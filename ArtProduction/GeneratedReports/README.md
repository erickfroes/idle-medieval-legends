# Generated reports

Saída local dos validadores e ferramentas de produção. O conteúdo gerado desta pasta é ignorado pelo Git; este README é a única exceção versionada.

Execute:

```powershell
& ./ArtProduction/Tools/Validate-ArtProduction.ps1
```

Use `-CheckOnly` para validar sem regravar o índice consolidado nem relatórios.
