## Uso recomendado

1. Aprovar os prompts de conceito.
2. Gerar as pranchas multi-view.
3. Aprovar silhueta e consistência entre vistas.
4. Usar a imagem aprovada no Image to 3D/Multi-view.
5. Aplicar Remesh, textura, rig e validação Unity.

A geração final de imagens e malhas não está incluída neste pacote.
