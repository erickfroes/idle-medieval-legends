# Incoming

Área de quarentena para downloads brutos e entregas ainda não verificadas.

- Preserve o nome original recebido.
- Não trate o conteúdo como aprovado nem como asset Unity.
- Extraia cada pacote em uma pasta própria antes da validação.
- Não mantenha o ZIP ao lado da cópia extraída, salvo exceção registrada em `ArtProduction/MANIFEST.json`.
- Downloads incompletos, caches e arquivos temporários são ignorados pelo Git.

Depois da inspeção, documentos e prompts versionáveis seguem para o pacote de origem; candidatos selecionados seguem para `ArtProduction/Approved`.
