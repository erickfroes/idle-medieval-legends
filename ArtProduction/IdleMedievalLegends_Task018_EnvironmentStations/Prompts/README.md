# Prompts — Task 018

Para cada um dos 85 assets existem:

1. concept sheet;
2. prompt de geometria Meshy;
3. prompt de textura PBR.

Total individual: 255 arquivos.

Há ainda 3 prompts de visão geral dos biomas e 5 prompts de evolução das estações.

## Fluxo

1. Aprovar o conceito.
2. Gerar somente o objeto/módulo isolado.
3. Remesh.
4. Unwrap UV quando necessário.
5. Texturizar.
6. Corrigir escala, pivô, snap e sockets.
7. Exportar FBX.
8. Criar prefab URP no Unity.
9. Adicionar VFX e partes animadas separadamente.

Nunca peça ao Meshy para gerar a dungeon inteira em uma única malha.
